# Архитектура информационной системы поликлиники

## Общая архитектура

Для системы выбрана трехуровневая клиент-серверная архитектура. Серверная часть реализуется как модульный монолит: все функции находятся в одном приложении, но разделены на модули.

Система предназначена для пациентов, врачей, сотрудников регистратуры и администраторов.

## Технологии

- Frontend: React, TypeScript.
- Backend: Java, Spring Boot, Spring MVC.
- Авторизация и права доступа: Spring Security.
- Работа с данными: Spring Data JPA, Spring JDBC.
- База данных: PostgreSQL.

## Схема работы

Пользователь → React → REST API (Spring Boot) → PostgreSQL

React отображает страницы и отправляет запросы на сервер. Spring Boot обрабатывает запросы, проверяет права доступа и выполняет бизнес-логику. PostgreSQL хранит данные системы.

## Основные модули

- Пользователи и роли.
- Врачи и расписания.
- Запись на прием и динамические квоты.
- Направления и эпизоды заболеваний.
- Медицинские записи и предварительные опросы.
- Уведомления и аналитика.

Модули взаимодействуют внутри одного серверного приложения. Для обычных запросов к базе данных используется JPA, для отдельных операций и функций PostgreSQL - JDBC и PL/pgSQL.

## Нагрузка

Система рассчитана на 5000 зарегистрированных пациентов и не менее 200 одновременно активных пользователей, в том числе при открытии новых слотов записи. Запись на один слот должна выполняться без конфликтов при одновременных запросах.
