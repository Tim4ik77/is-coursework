# Подготовка публикации

Материалы исходного репозитория получены через подключение GitHub на коммите `29f9fc716b96b5760be16ae9563899b8c59c12a6`.

Прямой `git clone` в рабочей среде не выполнен: сетевое соединение с github.com:443 недоступно. Подключение GitHub позволяет читать репозиторий, но обе попытки записи (Git Blobs API и Contents API) вернули `403 Resource not accessible by integration`. Удаленный репозиторий не изменен.

Локальная папка `is-coursework` — восстановленный снимок файлов с подготовленными изменениями, **не полноценный клон исходной истории**. Для переноса без потери исходной истории рядом с ней подготовлены `stage2-ready.patch` (git format-patch с бинарными файлами) и `publish-stage2.ps1`. Скрипт клонирует настоящий репозиторий, проверяет исходный commit, применяет патч через `git am` и выполняет обычный push без force.

Запуск из обычного PowerShell с доступом к GitHub и авторизацией Git:

```powershell
./publish-stage2.ps1
```

Если ветка изменится до публикации, скрипт остановится и оставит клон для ручной проверки. Локальную синтетическую историю не следует отправлять напрямую в `main`.
